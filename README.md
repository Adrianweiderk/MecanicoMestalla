# Calculadora del Mecánico

Calculadora estática de servicios y presupuestos para un taller mecánico. Está hecha con HTML, CSS y JavaScript; no necesita Python, servidor ni dependencias.

## Publicar en GitHub Pages

1. Sube `index.html` al repositorio.
2. Abre **Settings > Pages** en GitHub.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona la rama que contiene estos archivos y la carpeta `/(root)`, y guarda.
5. Abre la URL que GitHub Pages muestra en esa misma sección. La portada redirige a la calculadora.

Los cambios pueden tardar unos minutos en publicarse. También puedes abrir `index.html` directamente en el navegador para probarla en local.
